Auto Spares Enterprise Application

Offline-first POS & Inventory Management

An enterprise-grade tablet application designed for auto spare shops with rigid staff accountability, instant local saves, and cloud syncing.

Architecture Breakdown

Phase 1: Authentication
Features a custom secure numpad. Master Admins use a master code to provision staff and generate OTPs. New hires use OTPs to set private PINs. Sessions track user actions for strict accountability.
Phase 2: Role-Based Routing
  • Cashiers: Access Point of Sale, build digital carts, send pending orders to the warehouse, handle checkout (Cash/M-Pesa/Credit), and manage the ledger.
  • Store/Warehouse: View live active tasks, pick items, and notify the counter when ready.
  • Executive Owner: Full register access plus macro analytics (Revenue, M-Pesa/Cash splits, and critical low-stock alerts).
Phase 3: The Unseen Data Engine
Built on an offline-first architecture. Uses Isar database for instant UI reaction (zero loading spinners). A background SyncQueue pushes JSON receipts to Firebase every 3 minutes. Network resilient—stores receipts safely if Wi-Fi drops.

Matatu Tracker

Real-Time Urban Transit Telemetry

A low-latency telemetry network for Kenyan transit. It drops transactional booking entirely to focus purely on linking commuter demand with driver locations.

Architecture Breakdown

Phase 1: Hardware-Accelerated Init
Fast Google Sign-In, instant GPS hardware handshake, and a Google Map canvas that loads in milliseconds, centering on the user.
Phase 2: Route Snapping
Users select corridors (e.g., CBD to Thika Superhighway). The app queries Firestore for stage coordinates and Google Directions API to unpack a polyline string, rendering a sharp path that hugs the actual road lanes.
Phase 3: Commuter View
Streams active fleet vehicles. Custom markers physically rotate to match the driver's trajectory vector. Tapping a stage compares vehicle coordinates against the road polyline for exact ETAs.
Phase 4: Driver/SACCO View
Passive demand mapping. Passengers opening the app create anonymous heatmaps. Drivers see visual indicator rings at upcoming stages (e.g., Roysambu, Githurai) to optimize pacing and capture demand.
Phase 5: Cloud Sync Loop
Zero-friction payloads update telemetry continuously, allowing driver and passenger interfaces to sync with near-zero lag.
